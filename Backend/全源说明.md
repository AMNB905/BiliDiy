# BiliDiy 后端全源说明

这是 BiliDiy 云端后端的完整 PHP 源码，包含：

- `api.php`：客户端 API
- `admin.php`：管理后台
- `lib/storage.php`、`lib/security.php`：存储与安全工具
- `u_f4ff6904bfb5.php`：受保护的部署接收端（源码中的 Token 已替换为占位符）
- `data/config.example.php`：数据配置示例

## 3.9.33 好友在线状态

`api.php` 新增：

- `account_last_active($store, $u)`：综合账号 `last_login` 与有效会话 `last_at` 取最大值
- `friend_list` 返回每个好友的 `last_at`（秒）与 `online`（5 分钟内活跃）
- `friend_list_for()` 按在线优先、再按昵称排序
- `friend_list` 动作会调用 `account_touch_activity()`，有变化时 `store_save()`，让打开好友页的当前账号刷新活跃时间

客户端会展示“在线 / 刚刚活跃 / N 分钟前活跃 / N 小时前活跃 / N 天前活跃 / 很久未上线 / 最近活跃未知”。该改动需要部署到生产环境后才会生效。

## 3.9.31 好友与会员分享

`api.php` 新增：

- 好友：`friend_list`、`friend_search`、`friend_request`、`friend_requests`、`friend_accept`、`friend_reject`、`friend_remove`
- 分享：`share_create`、`share_list`、`share_revoke`、`share_revoke_all`、`share_refresh`、`share_playurl`

`lib/storage.php` 会额外持久化：

- `data/friends.php`
- `data/friend_requests.php`
- `data/shares.php`
- `data/share_cookies.php`

分享 Cookie 加密密钥自动生成在 `data/.security/share.key`，权限 `0600`。生产环境必须保证 `data/.security/` 不可被 Web 直接访问。

分享只保存播放必需字段，不保存 `bili_jct`；`share_playurl` 只返回 PGC `playurl` 的视频流结果，不返回 Cookie。被分享方无法用分享者身份做搜索、点赞、收藏、下载等操作。

## 未包含

- `data/` 下的真实配置、B 站 Cookie、管理员密码哈希、账号会话、会员/设备记录、观看历史
- `download/` 下已上传的 APK
- 生产环境的部署 Token、管理员密码和服务器地址

这些文件包含可直接接管账号的凭据，必须由部署者自行生成。

## 部署

1. 环境：PHP 7.4+，需要可写 `data/` 与 `data/history/`。
2. 上传 `api.php`、`admin.php`、`lib/`、`u_f4ff6904bfb5.php`。
3. 复制 `data/config.example.php` 为 `data/config.php`，设置：
   - `client_key`：自定义客户端 key，并同步改客户端源码中的 `CLIENT_KEY`
   - `setup_token`：初始化管理员密码用的随机令牌
   - `cookie`：先留空，登录后台后再粘贴完整 B 站 Cookie
4. 浏览器打开 `admin.php`，用 `setup_token` 设置管理员密码。
5. 确认 `data/.htaccess` 生效，或使用 Nginx 规则禁止直接访问 `data/`。

## 部署接收端

`u_f4ff6904bfb5.php` 中的：

```php
const DEPLOY_TOKEN = 'CHANGE_ME_DEPLOY_TOKEN_32_BYTES';
```

必须替换为至少 32 字节的随机值，并与你的部署脚本请求头 `X-Deploy-Token` 保持一致。不要把真实 Token 提交到仓库或发给他人。

## 客户端 key 对应位置

- Android：`app/src/main/java/com/gdk/biliapp/Cloud.kt` 中的 `CLIENT_KEY`
- Windows：`src/main/cloud.js` 中的 `CLIENT_KEY`

三处必须一致，否则客户端会收到 `client key 无效`。
