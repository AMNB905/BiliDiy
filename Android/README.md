# BiliDiy v3.9.39 — B 站「搜索 + 播放」客户端

原生 Android 客户端（Kotlin + Media3/ExoPlayer），只做两件事：**搜得到**（视频 / 番剧 / 影视）和**播得动**（含电影、番剧选集）。界面固定为浅色 Material 3，所有背景、卡片、按钮与导航均使用浅色填充，只有正文文字保留深灰以保证可读性。

- **搜索框固定在顶部**：首页 header 中的搜索框仍位于列表之前，不随内容滚动；搜索页顶部同样只保留返回键 + 固定搜索框，输入区和结果区分别在下方滚动。
- **搜索页取消分类 tab 栏**：移除视频 / 番剧 / 影视三个横排分类 chip，类型筛选收进搜索框内的「视频 ▾」菜单，页面顶部不再出现 tab 栏。
- **业务不变**：本机历史 / B站历史拆分、B站大会员 > BiliDiy 激活 > 好友分享的权益优先级、社交 2.0、会员分享、下载队列和签名升级链全部保留。

## v3.9.35 杜比 / FLAC / AAC 多音轨

- **多音轨解析**：`MpdBuilder` 同时解析 `dash.audio`、`dash.dolby.audio`、`dash.flac.audio`，把 AAC、FLAC 无损、杜比 E-AC-3 写入同一个音频 AdaptationSet。
- **设备能力探测**：新增 `AudioTracks.kt`，用 `MediaCodecList` 检查本机是否有 `audio/eac3`、`audio/eac3-joc`、`audio/ac3`、`audio/flac` 解码器；没有杜比解码器的设备不会强行选杜比轨。
- **播放页音轨菜单**：竖屏「音轨」按钮和横屏音轨 chip 都可切换「自动 / 杜比 / FLAC 无损 / AAC」；当前音轨与编码信息会显示在状态行。
- **自动回退**：默认自动优先杜比，其次 FLAC，最后 AAC；设备不支持或视频没有对应轨道时回退 AAC，避免“有画面无声”。
- **偏好记忆**：音轨选择写入 `PlaybackPrefs`，换视频 / 重启 App 继续沿用；MP4 兼容模式固定显示「单轨」。
- **说明**：杜比需要设备自带解码器或外接音响透传；手机扬声器本身是立体声，杜比全景声会被系统下混。App 不伪造杜比渲染，也不内置 Dolby SDK。

## v3.9.32 观看历史拆分

- **本机历史只属于本机**：`History` 只保存本机 SharedPreferences，不再把 B站账号历史合并进首页「本机继续观看」。
- **B站历史独立保存**：新增 `BiliHistory`，使用独立 SharedPreferences，按当前绑定 B站 UID 归属，最多 300 条，换绑 UID 立即清空旧账号缓存。
- **同步语义调整**：`BiliSync` 同步结果直接替换 B站独立历史；设置页与用户中心读取 `BiliHistory` 的条数和最后同步时间。
- **启动不再回灌**：删除 `CloudHistory.pull()`，启动时不再拉取云端设备历史反向合并。
- **用户中心双来源**：新增「本机历史 / B站账号」切换；B站来源右上角按钮为「同步」，只刷新本机 B站缓存，不删除 B站服务器记录。
- **解绑提示**：解绑 B站账号只删除 Cookie、追番与独立历史缓存，不影响本机观看历史。

## v3.9.31 调整

- **识别 B 站大会员**：绑定 B 站账号后读取 `nav` 的 `vipStatus` / `vipDueDate`；有效大会员可直接播放会员专享内容，不再要求 App 激活。
- **会员权益优先级**：B 站大会员 > App 激活 > 好友分享；设置页会员卡会显示当前来源和大会员到期时间。
- **App 账号好友**：设置页新增「好友与会员分享」入口，按 App 登录用户名搜索、发送申请、接受/拒绝、删除好友。
- **好友会员分享**：大会员账号可给好友分享 1–365 天会员；同一好友重复分享会顺延到期时间，最多同时分享给 5 位好友。
- **只播放，不越权**：被分享账号播放 PGC 会员内容时，由服务端使用分享者加密保存的播放 Cookie 代理 `playurl`；客户端只拿到视频流地址，拿不到 `SESSDATA` / `bili_jct`。分享播放不提供下载、搜索、点赞、收藏等业务。
- **分享安全**：分享 Cookie 只保留播放必需字段，不保存 `bili_jct`；服务端 AES-256-GCM 加密落盘，分享创建/刷新时校验 B 站登录态和大会员有效期。

## v3.9.30 调整

## 个人 B站账号 Cookie 获取

个人账号绑定不需要手动粘贴 Cookie，也不需要抓包：

1. 设置页 →「B站账号」→「绑定」，打开 B站官方登录页 `https://passport.bilibili.com/login`；
2. 用户在官方页面完成登录（密码 / 短信 / 扫码由 B站页面决定）；
3. 登录成功后，客户端从 Android `CookieManager` 读取 `SESSDATA`、`DedeUserID`、`bili_jct` 等 Cookie；
4. 调用 `x/web-interface/nav` 校验登录态，成功后用 Android Keystore AES-GCM 加密保存到本机；
5. 解绑时删除本机 Cookie 与追番列表。

个人 Cookie 只用于本机请求 B站接口，不上传到 BiliDiy 服务器。详细流程见 `docs/B站账号绑定说明.md`。

## 云端播放 Cookie 更新

云端 Cookie 是给未绑定个人账号时的播放兜底，不是个人账号 Cookie：

1. 浏览器登录 bilibili.com → F12 → Application → Cookies → 复制整串（需包含 `SESSDATA`、`bili_jct`）；
2. 打开后台 `https://xiaorou.top/BILILI/admin.php` →「云端 Cookie」→ 粘贴保存；
3. App 重新打开即生效，播放源恢复为云端 Cookie 对应权限。

## 关键技术要点

- **电影搜索**：`/x/web-interface/wbi/search/type?search_type=media_ft` 返回 `season_id`，不是 `bvid`
- **PGC 播放**：`/pgc/view/web/season` 取 `episodes[].id` → `/pgc/player/web/playurl?ep_id=&qn=&fnval=4048`
- **付费影片**：`result` 里没有 `dash`，只有 `durl`（`is_preview=1`，约 6 分钟试看）；会员片走正常 DASH
- **WBI 签名**：playurl / 搜索 / 空间接口必须 `w_rid/wts`（nav 取 key + mixin 表 + MD5）
- **防盗链**：媒体请求必须带 `Referer: https://www.bilibili.com/`
- **MPD 时长**：`timelength` 在 playurl 结果顶层（曾因读错层级导致 dur=0 黑屏）

## 已知边界

- 影视「付费」单片（非大会员权益）只能播放试看片段，完整版需在 B 站购买，App 会提示
- 部分影视条目受地区/版权限制，接口直接无剧集或播放失败
- `bili_ticket`（Cookie 内的风控参数）会过期；过期后搜索会走未签名降级接口，可能触发风控
