# BiliDiy Android 3.9.39 全源说明

这是 Android 客户端的完整工程源码，已排除以下内容：

- `build/`、`app/build/`、`.gradle/`、`.kotlin/` 等构建产物和缓存
- `local.properties`（本机 SDK 路径）
- 签名私钥、`keystore.properties` 以及任何 `.jks` / `.keystore` 文件

签名密钥不会随源码分发。工程默认构建 **unsigned release APK**，再用 `apksigner` 签名：

1. 安装 JDK 17，并配置 `JAVA_HOME`。
2. 在 `local.properties` 写入 `sdk.dir=你的 Android SDK 路径`。
3. 构建：

```bat
gradlew.bat assembleRelease
```

输出在 `app/build/outputs/apk/release/app-release-unsigned.apk`。

4. 使用 PKCS#8 私钥与 X.509 证书签名：

```bat
apksigner sign --key your-key.pk8 --cert your-cert.pem ^
  --out app-release.apk app-release-unsigned.apk
```

如果本机没有 Android SDK，可先安装 Android Studio 或命令行 SDK，至少包含 `platforms/android-35` 与 `build-tools/35.0.0`。

主要源码目录：

- `app/src/main/java/com/gdk/biliapp/`：Kotlin 业务代码
- `app/src/main/res/`：布局、图标、主题
- `app/src/main/AndroidManifest.xml`：权限与组件声明
- `app/build.gradle.kts`：版本、依赖与 R8 配置
- `../Backend/`：后端 PHP 全源（单独目录）
