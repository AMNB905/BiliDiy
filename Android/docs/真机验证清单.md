# BiliDiy v3.5.1 真机验证清单

安装 `BiliDiy-3.5.1-release.apk`（versionCode=27 / versionName=3.5.1，新密钥签名；从 3.2.x 升级必须先卸载）。
本轮验「搜索 + 播放」+「头像 / 用户中心」+「首页布局与播放记录」。任何一项失败：截图现象，并把页面底部的状态文字一并截图。

## ① 搜索 · 视频
- [ ] 打开 App 默认显示「热门推荐」双列卡片（封面 / 时长 / 标题 / UP 名）
- [ ] 输入关键词（如「原神」）→ 搜索 → 出现视频结果
- [ ] 向下滚动能继续加载（分页）

## ② 搜索 · 影视（本次重点）
- [ ] 点「影视」chip → 输入「流浪地球」→ 出现影视海报卡（带评分角标）
- [ ] 输入「肖申克的救赎」「奥本海默」同样有结果
- [ ] 点任一张海报 → 进入详情页（海报 / 标题 / 评分 / 地区类型 / 简介 / 版本列表）

## ③ 搜索 · 番剧

- [ ] 点进详情页 → 看到 12 集选集网格

## ④ 播放 · 投稿视频

- [ ] 播放时画面上没有常驻控制条；单击画面才出现底部「播放/暂停 + 细进度条 + 时间」
- [ ] 浮层出现后约 3.5 秒自动收起；暂停时浮层保持显示
- [ ] 拖动细进度条能跳转，时间跟着变
- [ ] 「画质」能切换（如 1080P ↔ 720P），切换后从当前位置继续
- [ ] 「倍速」选 1.5x 生效
- [ ] 多P视频出现「分P(N)」按钮，切换后重新播放

## ⑭ 设备账户（无密码）
- [ ] 设置页顶部出现「账户」卡片：粉色圆形首字头像、昵称、灰色「设备 ID · dev_…」
- [ ] 首次安装昵称默认「用户」+ 设备 ID 后 4 位

- [ ] 昵称超过 16 字会被截断；留空保存显示「匿名用户」
- [ ] 有网时设备行末尾显示「已同步到云端」；断网保存显示「本地保存」（恢复网络重进设置页会再同步）
- [ ] 后台 `admin.php` 的「设备账户」卡片出现这台设备（device_id / 昵称 / 版本 · 机型 · 时间），状态卡显示「N 台设备」
- [ ] 没有出现登录/注册/密码任何入口

## ⑮ 观看历史与续播
- [ ] 看任意视频到 1 分钟以上后退出 → 首页出现「继续观看」横排卡片（封面 + 标题 + 「看到 mm:ss · n%」）
- [ ] 「继续观看」位于列表内部：向下滚动时它跟着列表一起滚出屏幕，不再固定压在内容区上方
- [ ] 滚回顶部能看到「继续观看」；再往下滚，下方网格卡的高度不变、不被压缩
- [ ] 顶部只有一层分区标题：热门时顺序为「继续观看 → 热门推荐 → 网格」，不出现两个固定标题条
- [ ] 输入关键词开始搜索 → 「继续观看」整块自动消失，结果区拿到全部高度
- [ ] 点 ✕ 清空关键词回到热门 → 「继续观看」自动恢复（有记录时）
- [ ] 点这张卡片 → 直接回到上次位置继续播（状态栏提示「已从 mm:ss 续播」）
- [ ] 播到接近片尾（最后 5 秒）退出 → 该条进度归零，再点从头开始
- [ ] 看第二个视频后，最新一条排在最前；连续看 40 个不同视频，记录仍是 40 条（不再截断）
- [ ] 长按某张历史卡片 → 提示「已从历史中移除」后卡片消失
- [ ] 首页「清空」→ 二次确认 → 横排整块隐藏，提示「已清空观看历史」
- [ ] 冷启动 App 后历史仍在；多P视频切换到第 2P，进度按 P 分别记录
- [ ] 番剧/影视同样出现在「继续观看」，点开回到对应集数与进度

## ⑯ 用户中心与头像
- [ ] 设置页「账户」卡片点一下 → 进入「用户中心」，顶部显示头像 / 昵称 / 设备 ID / 同步状态
- [ ] 点「换头像」或直接点头像 → 打开系统相册；选一张竖图/横图，保存后头像变成圆形不拉伸
- [ ] 换头像后返回设置页、再回首页、杀掉 App 重开，头像仍在（不恢复成首字）
- [ ] 在用户中心点「改昵称」→ 保存后顶部昵称与设置页同步；超过 16 字被截断
- [ ] 用户中心「播放记录」列出全部记录（封面 / 标题 / 看到 mm:ss / 时间），数量与首页「继续观看」一致
- [ ] 点任意一条 → 回到对应视频并续播；看完返回，该条进度已更新
- [ ] 点右侧「×」→ 二次确认后单条消失；长按同样可移除
- [ ] 「清空」→ 二次确认 → 列表空态文案出现，首页「继续观看」整块隐藏
- [ ] 播放 40 个以上不同视频后，用户中心仍完整显示，滑动不卡顿
