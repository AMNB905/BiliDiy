> 生成日期：2026-11-18 · 版本 v3.0.0（versionCode=20）· 脚本在 `tools/`（`test_movie_search*.py`、`test_pgc_*.py`、`test_mpd_v3.py`、`test_stream_v3.py`），全部可复现

## 一、本轮目标

1. 修复「搜不到电影」：v2 只查 `search_type=video`（UGC 投稿），电影在 B 站属于 PGC 影视库（`media_ft`）
2. 功能做减法：只留搜索 + 播放（画质 / 倍速 / 分P / 进度）
3. UI 重构：浅色干净，单页搜索

## 三、v3 代码侧关键修正

- `BiliApi.search(SearchKind, ...)`：三类搜索走同一套 WBI 签名 + `bili_ticket` + 未签名接口降级
- `MpdBuilder`：按服务端实际 `quality` 选流；编码优先级 `avc1 > hev1/hvc1 > av01 > dvh1`；音轨优先 AAC，避开 `ec-3`/`flac`
- `VideoActivity`：新增 PGC 分支（`ep_id`），DASH → `durl` → html5 MP4 三级兜底
- `PgcDetailActivity`：影视/番剧统一详情页，支持版本（电影）与选集（番剧）
